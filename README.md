# Quantum-Enhanced Data Analytics for Crime Prediction

Paper presented at the **2025 SNPD International Conference**.

**Authors:** Abraham Ighalo and Ajmery Sultana, School of Computer Science and Technology, Algoma University

📄 [Read the paper](https://ieeexplore.ieee.org/document/11253302/authors#authors)

## Summary

This study compares classical and quantum machine learning models for classifying criminal incidents, using the NYPD Complaint Dataset.

- **Classical models:** Logistic Regression, Random Forest, XGBoost, SVM
- **Quantum models:** Variational Quantum Classifier (VQC), Quantum Neural Network (QNN), Quantum SVM (QSVM)

Ensemble methods (Random Forest and XGBoost) performed best. The quantum models show theoretical promise but currently fall behind in practice because of hardware limitations.

**Keywords:** Quantum Machine Learning, Quantum Data Analytics, Predictive Policing, Crime Detection, Classical Machine Learning
